# E-Commmerce_JewelleryShop (Python-Django)

A modern online jewellery store template built with HTML, CSS, JavaScript, Tailwind CSS, and powered on the backend by Python and Django. This full-stack e-commerce project allows users to browse products, view product details, add items to cart, register/login, and place orders. The admin side enables product and order management.

🔗 Live Demo

➡️ https://github.com/dhrumilc2005-a11y/E-Commerce_JewelleryShop.git

📦 Features
🛍️ Frontend

✔ Clean UI for products listing, categories, and details
✔ Responsive design using Tailwind CSS utility classes
✔ Client-side interactivity via JavaScript (product filtering, cart updates)
✔ Product search functionality
✔ User registration & login pages

🔧 Backend (Django)

✔ Built with Django (Python) — MVC framework for rapid development
✔ Product management (CRUD) via Django Admin
✔ User authentication (login/signup/logout)
✔ Shopping cart logic stored in session
✔ Order placement and history
✔ Secure form handling and validation

Clone the Repository
git clone https://github.com/dhrumilc2005-a11y/E-Commerce_JewelleryShop.git
cd E-Commerce_JewelleryShop

Create & Activate Python Environment
python3 -m venv venv
# On Windows
venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate

Install Dependencies
pip install -r requirements.txt

Apply Migrations
python manage.py makemigrations
python manage.py migrate

Create Super User (Admin)
python manage.py createsuperuser

Run the Development Server
python manage.py runserver

Visit:

http://127.0.0.1:8000/
